# Approved card editions

These twelve native frame assets, fonts, rank images, coordinates and colors come
from the supplied Card-Edition-Studio-Checkpoint.html. The example photograph,
unfinished editions and archived alternatives are excluded. Christmas is included
in the approval record. Frame hashes in catalog.json verify the original bytes.

The standalone builder embeds these shared assets once, so the card artwork needs
no remote image requests. Labels remain live and use the saved per-frame bounds.
Bronze, Diamond and Grandmaster use the approved studio emblems. Other existing
rank tiers retain their current app emblems and fit inside the same rank surface.

Automatic editions use existing qualified #1 and recorded Former #1 provenance.
The ten other editions are selected manually from Card customization on the back
of an enlarged image or set card. Base card explicitly opts out of edition artwork.
Captain remains a separate eligible corner crest. Choices, rating display and
Captain visibility/corner persist as collection metadata with revision checks.

Photo framing defaults to fill opening, with optional contain, zoom and X/Y.
Original media, battle ratings/history, duplicate review and organizer data are
not rewritten by appearance edits. Native source assets must not be replaced by
compressed chat previews.

Validation: runtime edition, existing card-feature and collection tests; actual
standalone browser interaction, refresh persistence, all twelve frame renders,
all seven rank tiers, portrait/landscape framing, set mosaics and hidden ratings.
